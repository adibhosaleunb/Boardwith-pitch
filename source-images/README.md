# Source images

Drop the original attached files here, then run `npm run images`. The script
writes the WebP/PNG files the deck uses into `public/images/` (and the favicon).
Originals in this folder are git-ignored; the converted files are what you commit.

| Put this file here | Becomes | Slide |
| --- | --- | --- |
| `boardwith-lockup-on-teal.png` | `public/images/logo-lockup.png` + `public/favicon.png` | 1, 10 |
| `Lost_at_the_Airport@2x.png` (or `Lost_at_the_Airport2x.png`) | `public/images/problem-alone.webp` | 2 |
| `With_someone@2x.png` (or `With_someone2x.png`) | `public/images/solution-together.webp` | 3 |
| `pexels-tafsinnaeem-35444544.jpg` | `public/images/cover-parent.webp` | 1 |

Do not use the other attached images (iStock/Shutterstock previews, the
"Heartbreak at the gate" screenshot, the couple and wheelchair photos, generic
stock). The brief, section 12.4, lists why.
